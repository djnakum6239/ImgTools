# ImgTools

Native Android port of ImageForge: https://github.com/LyraVoid/ImageForge

Goal: standalone offline-first Android image tooling with Kotlin/Compose UI and a Rust native engine. No server, account, telemetry, or cloud processing.

The project will implement ImageForge tool families incrementally: inspect, OTA extraction, sparse/super inspection, boot/ramdisk processing, boot logo, boot animation, comparison, and supported local patch pipelines.
